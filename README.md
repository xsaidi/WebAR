# ФОРМА / 01

Адаптивный лендинг учебного WebAR-проекта. Чистые HTML, CSS и JavaScript без сборки и зависимостей.

## Запуск

Откройте `dist/index.html` в браузере либо запустите статический HTTP-сервер из папки `dist`.

## Сейчас реализовано

- Одностраничная презентация дивана в стиле лофт.
- Четыре цвета обивки на SVG-эскизе, управление мышью, касанием и клавиатурой.
- Кнопка «Посмотреть диван» и доступное модальное окно с честным состоянием готовности модели.
- Адаптация под телефон и компьютер, видимый фокус, reduced motion.

Название, описание материалов и изображение — художественная концепция для курсовой, а не спецификация реального товара. Основное изображение иллюстративное. Эскиз показывает оттенки приблизительно; финальная 3D-модель пока отсутствует.

## Следующий этап: 3D / AR

После создания модели добавить GLB (и при необходимости USDZ для iOS), согласовать названия материалов и цветовые варианты. В обработчике `#view-sofa` заменить информационное окно настоящим просмотрщиком. На компьютере — вращение/масштабирование; на совместимом телефоне — доступная кнопка запуска AR с проверкой возможностей устройства и обычным 3D как резервным режимом. Само наличие телефона не гарантирует поддержку AR. Для доступа с телефона и AR нужен подходящий HTTPS-хостинг. Эта версия не запрашивает камеру и не имитирует размещение модели.
