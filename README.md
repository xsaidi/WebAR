# ФОРМА / 01

Адаптивный лендинг учебного WebAR-проекта: HTML, CSS, JavaScript и локальный model-viewer 4.3.1 (Apache-2.0, лицензия в dist/vendor).

## Запуск

Запустите статический HTTP-сервер из dist. Для AR на телефоне используйте опубликованный HTTPS-сайт, открытый отдельной вкладкой. Открытие index.html через file:// не поддерживает динамический импорт просмотрщика.

## 3D и оптимизация

- Четыре фотографии, четыре цвета обивки, вращение, приближение и сброс камеры.
- Библиотека и выбранный GLB загружаются только после «Посмотреть диван».
- Каждый GLB: около 341 КиБ, 11 112 треугольников, один меш с тремя материалами. Встроенная normal map; нет внешних текстур и декодеров Draco/KTX2.
- Нет автоматического вращения, анимации и динамической тени. Запрошен low-power WebGL, включено адаптивное снижение разрешения model-viewer.
- При закрытии модель удаляется, её кэш отключён. Библиотека и общий WebGL renderer могут оставаться в памяти; полное освобождение браузерной памяти не гарантируется.
- Быстрая смена цвета объединяется задержкой 160 мс. Ошибки загрузки показывают повторную попытку. При отсутствии AR остаётся обычный 3D.

## Android / iOS

Android: WebXR в Chrome на совместимом устройстве с установленными Google Play Services для AR. HTTPS, разрешение камеры и поддержка ARCore обязательны. Поддержку определяет просмотрщик, а не только название ОС.

iOS/iPadOS: Safari и системный AR Quick Look. USDZ создаётся из выбранного GLB при запуске; отдельное приложение не требуется. Текстуры USDZ ограничены 512 px. Цвет выбирается до запуска AR; для смены цвета выйдите из AR и запустите его снова.

Сайт сейчас закрыт авторизацией владельца. Android Scene Viewer отключён: отдельное приложение не может скачать защищённый GLB с браузерной сессией. WebXR и локальный USDZ обходят эту проблему без изменения приватности. На телефоне нужно войти в тот же аккаунт. После изменения аудитории можно отдельно добавить Scene Viewer как дополнительный Android fallback.

Встроенные браузеры мессенджеров, iframe без разрешения xr-spatial-tracking, неподдерживаемые телефоны и отказ в доступе к камере могут не запускать AR. Интерфейс сообщает об ограничении и сохраняет 3D. Для размещения нужны свет и различимая свободная поверхность пола. Масштаб фиксированный; ширина концепта 220 см, размеры восстановлены приблизительно по изображениям.

## Проверки

Проверено в настольном браузере: реальный рендер, четыре цвета, быстрое возвращение к прежнему цвету, закрытие и повторное открытие, отсутствие модельного элемента после закрытия, адаптивное окно. GLB проверены по структуре и рендером повторного импорта. Синтаксис JS проверен Node.

На физических Android/iPhone AR ещё не тестировалась. До защиты курсовой проверить Chrome/ARCore и Safari: разрешение/отказ камеры, размещение на полу, масштаб, все цвета, выход и повторный запуск, возврат из Quick Look, поворот экрана и слабое соединение. Замерить FPS и нагрев на слабом телефоне; гарантировать отсутствие задержек на любом устройстве по размеру GLB нельзя.

Документация: [model-viewer AR](https://modelviewer.dev/examples/augmentedreality/), [WebXR requirements](https://developers.google.com/ar/develop/webxr/requirements), [Apple Quick Look](https://developer.apple.com/documentation/arkit/previewing-a-model-with-ar-quick-look).

Описание материалов и размеры — художественная концепция для курсовой, а не спецификация реального товара.
