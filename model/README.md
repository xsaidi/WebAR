# ФОРМА / 01 — модель дивана

Модель вручную построена в Blender 5.2.2 через MCP по четырём изображениям пользователя. Геометрия, материалы и швы редактируются отдельно.

- `forma-sofa.blend` — основная сцена `FORMA - Sofa Studio`, коллекция дивана и отдельная студия со светом и камерой. Исходная стандартная сцена сохранена.
- `forma-sofa.glb` — терракота, только диван со встроенной текстурой normal map.
- `forma-sofa-graphite.glb`, `forma-sofa-sand.glb`, `forma-sofa-olive.glb` — остальные цвета.
- `sofa-preview.png` — рендер оригинала; `glb-preview.png` — проверка повторно импортированного GLB.
- `build_sofa.py` — воспроизводимая сборка геометрии и студии. Запускать один раз в новой сцене; повторный запуск создаёт ещё одну сцену.
- `export_sofa.py` — повторный экспорт четырёх цветов из сцены модели.

Ориентировочные размеры: ширина 2,20 м, глубина 0,96 м, высота около 0,98 м. Размеры восстановлены по пропорциям изображений, не по чертежу. Основание находится на уровне пола. В Blender лицевая сторона направлена по -Y; GLB экспортирован с обычным преобразованием осей Blender/glTF.

В экспортном файле 16 мешей, 17 312 треугольников, три материала и встроенная normal map ткани. Размер одного GLB — 398 172 байта. Свет, пол, камеры и стандартный куб в экспорт не включены. Материалы обивки и швов позволяют менять цвет независимо от ножек. Повторный импорт GLB и рендер проверены.

## Оптимизированная версия для сайта

`optimize_web.py` создаёт отдельную экспортную сцену, уменьшает геометрию подушек и швов и объединяет меши, сохраняя три материала. Исходная Blender-сцена не изменяется. Четыре результата в `../dist/assets/models/`: один меш, три примитива, 11 112 треугольников, около 349 408 байт на цвет. Сила normal map запечена в пиксели (normalScale=1) для совместимости с экспортом USDZ. `optimized-preview.png` — контрольный рендер этой версии.

Модель подключена к лендингу. AR и ограничения платформ описаны в основном README. Для финальной проверки масштаба в AR стоит согласовать реальные размеры дивана.
